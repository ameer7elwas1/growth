# مجلد SQL - SQL Directory

هذا المجلد يحتوي على جميع ملفات SQL للهجرة والتحديثات.

## الملفات

- `migrate_*.sql` - ملفات الهجرة
- `update_*.sql` - ملفات التحديث
- `add_project_id_to_users.sql` - إضافة عمود project_id لجدول users (لتمييز المستخدمين حسب المشروع)

## الاستخدام

قم بتشغيل هذه الملفات على قاعدة البيانات Supabase حسب الحاجة.

### إضافة project_id للمستخدمين

إذا كنت تستخدم أكثر من مشروع في نفس قاعدة البيانات، قم بتشغيل ملف `add_project_id_to_users.sql` لإضافة عمود `project_id` إلى جدول `users`. هذا سيسمح لكل مشروع بعرض مستخدميه فقط.
